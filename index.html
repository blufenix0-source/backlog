Claves API Gratuitas (Opcional)

El buscador ya incluye 6 motores públicos sin clave. Añade estas si quieres aún más portadas.

1. SteamGridDB API Key (Videojuegos) Motor de Steam ROM Manager

Consíguela gratis en steamgriddb.com/profile/preferences/api. Desbloquea miles de carátulas fan-made y oficiales.

2. TMDB API Key v3 (Películas, Series y Anime) Motor de Letterboxd

Consíguela gratis en themoviedb.org/settings/api. Extrae decenas de pósters alternativos y sin texto por película.

3. RAWG API Key (Videojuegos de Consola y Retro) +500,000 Juegos

Consíguela gratis en rawg.io/apidocs. Ideal para juegos de Nintendo, PlayStation y consolas clásicas.

4. ComicVine API Key (Cómics Marvel, DC, Indie) Enciclopedia de Cómics

Consíguela gratis en comicvine.gamespot.com/api/. Nota: Libros y Manga ya traen todo gratis sin clave con OpenLibrary, Google Books y AniList.
